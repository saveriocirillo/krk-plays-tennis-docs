The KRKplaysTennis API rates amateur tennis players in Kraków from the results of league and tournament matches. Use it to show players their rating, explain why it changed, suggest fair opponents, or submit results for a competition you run.

:::note[A fictional API]
KRKplaysTennis is a fictional API, built as a technical writing portfolio. The players, venues, and competitions are invented. You can run every example in these docs against a local mock server.
:::

## How ratings work

- A new player picks a starting level on the [NTRP self-rating scale](https://www.usta.com/en/home/coach-organize/tennis-tool-center/run-usta-programs/national/understanding-ntrp-ratings.html), from 1.5 to 5.5. The API converts it to a starting rating between 1000 and 1800.
- Each rated match moves the rating up or down, based on the result and on the opponent's rating.
- A confidence value from 0 to 100 shows how settled the rating is. A new rating moves quickly, and a settled rating moves slowly.

The rating comes from results, not from the self-assessment. The self-assessed level is only the starting point. For the full model, with worked examples, see [How ratings work](/portfolio/concepts/how-ratings-work/).

## Conventions

- **Base URL:** `https://api.krkplaystennis.example/v1`
- **Format:** JSON requests and responses.
- **Pagination:** list operations return `data` and a `next_cursor`. Pass `next_cursor` as `cursor` to get the next page.
- **Errors:** [RFC 9457](https://www.rfc-editor.org/rfc/rfc9457) problem details, with a `type` URL for each kind of error. See [Errors](/portfolio/errors/).
- **Times:** RFC 3339 timestamps. Availability windows use local time in Kraków (`Europe/Warsaw`).
