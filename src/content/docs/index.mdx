---
title: KRKplaysTennis API
description: Developer documentation for the KRKplaysTennis API, a fictional API that rates amateur tennis players in Kraków from real match results.
---

The KRKplaysTennis API collects match results from amateur tennis leagues and tournaments in Kraków and gives each player a rating based on those results. A player's self-assessed level sets the starting point. Each rated match moves the rating, and a confidence value shows how settled it is.

KRKplaysTennis is a fictional API. The players, clubs, and competitions in these docs are invented.
